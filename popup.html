The key is stored locally on this browser profile, not in Chrome Sync, and web pages cannot read it. Text you choose to fix or rewrite is sent to Anthropic. Nothing is sent until you click Fix or Rewrite or use a shortcut.

Both actions still appear when text is selected. This only changes which one is primary.

Get your API key at console.anthropic.com
Select text in a supported editor, then choose Fix or Rewrite, or press Alt+Shift+F / Alt+Shift+R.
